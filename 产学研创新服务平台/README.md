# 产学研创新服务平台爬虫 (学习版)
最简单的单页数据爬虫，用于 Python 爬虫技术学习与实践。

## 技术栈
- 语言：Python 3.13+
- 爬虫：requests BeautifulSoup
- 数据存储：控制台输出 / 本地文件

## 功能特性
### 请求头伪装、反爬规避
### 简易数据清洗与结构化输出

## 项目结构
- 产学研创新服务平台/
- ├── 产学研创新服务平台.py/ # 爬虫文件
- ├── 简单清洗.py          
- ├── 纯P标签简单清洗.py     

### 结构说明

#### 产学研创新服务平台.py
爬虫文件。

#### 简单清洗.py :
对于该平台而言，大部分企业榜单数据位于带 font-weight:bold 的 span 标签下，定位提取即可。

#### 纯P标签简单清洗.py 
该平台内一部分数据直接存在P标签内，因此做出一部分修改。

## 环境准备
1.安装依赖
pip install requests
pip install BeautifulSoup

## 运行方式
- 1.以https://www.sme-gov.cn/shandong-news-69941.html 为例，F12找到69941.html后复制curl格式填入 https://curlconverter.com/python/ 后将网址输出内容替换掉产学研创新服务平台.py中的cookies、headers、response即可。
- 2.观察得到的news_page.html，寻找目标位置，分辨是span标签还是P标签。
- 3.确定标签后直接运行后即可得到结果。
- 4.因为只为获取企业名称，所以并未对所得结果进行完备的清洗，同时纯P标签简单清洗.py因未做自动分列，所有的列为手动输入，因此网站中某些P标签数据需要根据得到的数据类型手动增减result中的列以及结尾输出的列数。
